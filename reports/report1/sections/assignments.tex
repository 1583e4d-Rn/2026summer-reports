\subsection{随机访问日志统计}

\subsubsection*{编写 analyze.sh 脚本完成日志统计}
本题要求编写一个 Shell 脚本 analyze.sh，功能如下：
\begin{itemize}
    \item 接受一个 CSV 文件路径作为唯一参数，文件不存在时输出错误到 stderr 并返回非零退出码。
    \item 输出 HTTP 5xx 数量最多的前 2 个 path（按次数降序，若相同按字典序）。
    \item 计算全部数据行的平均 latency\_ms（表头不计），保留两位小数。
    \item 不得使用 Python、电子表格或手工统计。
\end{itemize}

脚本如下：
\begin{minted}[frame=single, fontsize=\small]{bash}
#!/usr/bin/env bash

# 检查参数个数是否为1
if [ $# -ne 1 ]; then
    echo "Usage: $0 <csv-file>" >&2
    exit 1
fi

csv_file="$1"

# 检查文件是否存在
if [ ! -f "$csv_file" ]; then
    echo "Error: File '$csv_file' not found" >&2
    exit 1
fi

echo "Top 2 5xx paths:"

grep -v '^timestamp' "$csv_file" \   # 去掉表头行

    # 提取第4列（status）为5xx的，输出第3列（path）
    | awk -F, '$4 >= 500 && $4 < 600 {print $3}' \

    | sort \   # 排序以便 uniq 计数
    | uniq -c \  # 统计每个 path 出现次数
    | sort -k1,1nr -k2,2 \  # 先按次数降序，次数相同按 path 字典序
    | head -2 \  # 取前两名
    | awk '{print $2, $1}'  # 将输出格式调整为 "path 次数"

# 计算平均延迟，跳过表头并保留两位小数
avg=$(awk -F, 'NR > 1 {sum += $5; count++}
    END {if (count) printf "%.2f", sum/count; else print "0"}' "$csv_file")
echo "Average latency: $avg ms"
\end{minted}

\subsubsection*{运行脚本}
使用题目给定的 access.csv 运行：
\begin{minted}[frame=single, fontsize=\small]{bash}

\subsection{制造、解决并解释一次合并冲突}
本题要求主动制造、解决并解释一次合并冲突，详细如下：
\begin{itemize}
    \item 初始化仓库，在 main 创建 config.txt，内容为 mode=normal，并完成初始提交。
    \item 创建 feature-a，把内容改为 mode=safe 并提交；从初始 main 创建 feature-b，把内容改为 mode=fast 并提交。
    \item 回到 main，先合并 feature-a，再合并 feature-b；解决冲突时保留 mode=safe，并另加一行 note=reviewed。
    \item 确认工作区干净，运行 git log --all --graph --decorate --oneline 查看历史。
\end{itemize}

\subsubsection*{初始化 Git 仓库并提交}
首次提交前，需先设置姓名与邮件。
\begin{minted}[frame=single, fontsize=\small]{bash}
mkdir -p q03 && cd q03
git init
echo "mode == normal" > config.txt
git add config.txt
git commit -m "Initial commit with normal mode declaration"
\end{minted}

\subsubsection*{签出两个分支并各自修改}
\begin{minted}[frame=single, fontsize=\small]{bash}
git checkout -b feature-a
echo "mode == safe" > config.txt
git add config.txt
git commit -m "Set feature a to safe mode"

git checkout main
git checkout -b feature-b
echo "mode == fast" > config.txt
git add config.txt
git commit -m "Set feature b to fast mode"
\end{minted}

\subsubsection*{合并分支并解决冲突}
\begin{minted}[frame=single, fontsize=\small]{bash}
git checkout main
git merge feature-a   # 无冲突
git merge feature-b   # 产生冲突
# 手动编辑 config.txt，保留 "mode == safe" 并新增 "note == reviewed"
git add config.txt
git commit -m "Conflict solved"
\end{minted}

\subsection{修复并构建一页技术说明}

\maketitle

要求：
\begin{itemize}
\item 加入一个带编号和 label 的公式，并在正文中使用 ref 或 eqref 引用。
\item 加入一个 2 行 2 列表格，设置 caption 和 label，并在正文中引用该表。
\item 使用 latexmk -pdf -halt-on-error 或 tectonic 生成 report.pdf。
\item 确认 PDF 能打开，且交叉引用不显示“??”。
\end{itemize}
